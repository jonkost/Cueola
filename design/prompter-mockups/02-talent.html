Talent screen

The talent sees words, and almost nothing else. Crew notes never reach this screen. While it rolls, every control is hidden. The screen keeps the whole script on itself, so it can finish the show even if the link is gone.

Rolling, on air. A thin red line across the top means this row is on air. Words already read fade. The row name is small. The speaker is a tag. A yellow box is a note to the talent, not read aloud. Underlined words get punched.

Paused. The top bar and the control set come back. Same fifteen controls as the operator.

No operator. The talent or a floor person runs it right here, by touch, keys or a clicker.

Clock. One clock, top right, always says what it is counting.

Message from the booth. Wrap up with a countdown. The script keeps rolling under it.

Question. Same place, blue, so it is never mistaken for a wrap.

Rows with no script. A clip or a silent row is one thin line, not a blank gap. The clock counts the clip down. A red STOP line is where the roll stops by itself.

Slate: Standby. Before the show, and any time the operator presses Slate.

Slate: Technical difficulties. Tells the talent what to do, not just what broke.

Slate: Color bars.

Linked, no script yet. The show code is big enough to check from across the studio.

Link lost while rolling. It does not stop, jump or blank. One calm yellow note, and the controls appear here so someone on the floor can take over.

Link back. The operator's screen catches up to the talent, never the other way round. The words do not move.

Light theme (Polar Bear). Same layout, black on white.

Not linked. Leads straight to the show picker (see Show codes).
