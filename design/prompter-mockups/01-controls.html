The one control set

Fifteen controls. The same name, the same picture, the same order and the same size on every screen: the operator inside Live, the stand-alone operator, the talent screen, the keyboard and the Stream Deck. Three groups of five, so the screen and a 15-key Stream Deck are laid out the same way.

Paused. Play is the one filled button. Follow is lit because the prompter is following the rundown.

Rolling, clock up. Play turns green and reads Pause. A control that is on the talent's screen is lit yellow.

No talent screen linked. Everything dims together. Nothing looks pressable when it would do nothing.

One size per screen, never mixed

Every button in the set is the same size as its neighbours. Corners are a quarter of the height, the Apple push button shape. No outlines, no shadows.

Where the old controls went

Nothing a show needs is lost. The pile is smaller because several old buttons did the same job.

Brake, Boost, Reverse, ForwardBack and Ahead. Hold to move, let go to stop. Slower and Faster change the speed.
Scroll pad, Position slider, NudgeBack and Ahead, the mouse wheel on any preview, and the Stream Deck dial.
Cue Now, Cue Next, Cue RowFollow, Prev row and Next row. Turning Follow on jumps to the row on air.
Push to prompterGone. The script lives in the rundown rows, so the talent always has the current words. A change to the row on air waits for one Send change button.
Time, Duration, Count to, HideOne Clock control. Press to show or hide. Hold to pick which clock.
