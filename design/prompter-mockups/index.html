The new teleprompter

Design only. Nothing here is wired to the app. These pages show every screen of the rebuilt prompter so it can be approved before any of it is built. Use Light in the top bar to see each page in the light theme.

One control set

Fifteen controls with the same names, pictures, order and sizes on every screen and on the Stream Deck.

One script, in the rundown

Words live in each row's Script cell. No Push button. The prompter follows the TAKE.

It cannot fumble

The talent screen holds the whole script and keeps rolling if the link drops. Controls light only when the talent screen confirms.

Extra features to consider

None of these are in the core plan. Each one is optional.

Read time against row timeEvery row shows how long its words take to read, and warns when they will not fit the row. Shown in these mockups.
Clip countdown for the talentWhile a package plays, the talent screen counts down to when they are back on.
Pace to the clockThe roll gently speeds up or slows down so the words end when the row's time ends.
Rehearsal modeRun the prompter through the whole show without moving the live show or the clocks.
Two talent screensCamera 1 and camera 2 prompters roll together, each with its own mirror setting.
Phone as a remoteA talent with no operator runs their own prompter from a phone with Play, Back, Ahead and speed.
Scan to linkThe talent screen shows a square code. Point an iPad at it and the iPad becomes the operator.
Printed backup scriptOne button prints the script by row, in big type, for when the power goes out.
Voice followThe roll follows the talent's voice. Experimental, and only for practice, never the only way to run a show.

New words to approve

These would go in the glossary once approved: Prompter operator, Roll, Back, Ahead, Follow, Slate, Message, Wrap, Clear, Punch, Note to talent, Stop here.
