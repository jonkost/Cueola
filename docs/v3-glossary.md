# Cueola 3.0 glossary (§3)

One approved word per concept. This is the vocabulary for every label, button, status line and error in the app, and what Jon says in class. **Jon approves this before it is applied.** The evidence behind each choice (every rival name, with counts and file:line) is in docs/v3-copy-audit.md.

Rule of thumb: real control-room words are curriculum (cue, standby, take, on air, director, talent, lower third, VO, PKG, wrap). Developer words are jargon and never reach a student screen (sync, snapshot, payload, field, null, session, listener, heartbeat, ack, protocol, cache).

Brand names (Flowmingo, Outrangutan, Planda Bear, KeyWi Bird) stay as the titles of their own windows and nowhere else. Instructions, buttons and status text use the plain word.

## The words

| **wrap** | The moment the show ends and the crew is released. | End, END, finish, Estimated Wrap, Wrap Up |
| **talent** | The people on camera or on mic who read the prompter. | host, anchor, speaker (as generic labels); Talent (as a screen) |

| **clip** | One video or audio file playback can roll. | media item, file, cue (inside playback) |
| **pre-roll** | Seconds a playback clip rolls before it is on air. A property of the cue, set once, never a button. | READY · TRACK · ROLL, armed call, Manual TAKE |
| **planner** | Where the show's paperwork lives: call sheet, safety plan, positions, schedule, stage plot. Window title: Planda Bear. | Planda Bear (in copy), paperwork hub, hub, pre-production workspace, prep, PB |
| **paperwork** | The documents in the planner the show needs before show day. | package, paperwork package |
| **call sheet** | The one page that says when and where to be, and who to call. | Event Info, Current Call Sheet |

| **safety plan** | The page listing hazards, emergency contacts, first aid and PPE. | Site, Weather and Equipment |

| **crew** | Everyone working this show. Use "student" only on the instructor dashboard. | students, learners, users, people, viewers |
| **instructor** | The teacher account that creates shows and hands the director seat to a student. | admin, Admin, super admin, owner, INST |

## Rules the words follow

1. Buttons are verbs: Take, Add cue, Join show, Export paperwork, Open Live, Back to rundown.
2. States are shown, not pressed: STANDBY, ON AIR, done, Saved, Saving…, Not saved.
3. One word per screen for the same thing. The Live bar, the rundown header and the export never disagree.
4. Anything longer than one sentence goes behind an ⓘ. An ⓘ always means "explain this".

## Open questions for Jon

- **hold**: keep the word only if a HOLD control is adopted (brief §8, question 2). Without it, "pause" survives only for media transport.
- **planner vs paperwork** as the button label on the rundown bar. This glossary says "Planner"; it is one word away either way.
- **TRT**: real vocabulary. It is dropped from labels and lives in the duration ⓘ. Say the word if it should stay on the label.
