# Training Video Scripts & Click-Paths (v2.2, 2026-07)

Thirteen videos: one per Learning Hub lesson, the Instructor Quick Start, and
three v2.2 feature walkthroughs (V11, V12, V13).
**Voiceover scripts are NOT duplicated here** for the lesson videos: the
narration text for each lesson lives in
[content-reference.md](content-reference.md) (generated from the in-app
lessons; reading it aloud IS the script, and the Kokoro MP3s are a timing
reference). This file adds what the camera does: the click-path to perform
while each part of the narration plays. V11, V12, and V13 are not Learning Hub
lessons, so their beats below carry their own timecodes and say-this cues.

Recording is an owner errand and may trail past Aug 2 (decision 14 decides
hosting; lessons already render a **Watch the video** slot when a lesson's
`video:` field gets a URL).

Conventions: record at 1280×800, cursor visible, one take per numbered beat,
pause a beat on every toast. Demo content: **Load Demo** unless stated.

---

## V1 · What The Three Tools Do (`LH-start`, ~2 min)
1. Front page: hover the three cards (Cueola / Planda Bear / Flowmingo) as the
   intro names them.
2. **Load Demo** → rundown appears.
3. Topbar: open **Guide**, show the lesson list, click through two lessons.
4. Point at the show code badge while the narration hits "one shared
   show code".

## V2 · Your Profile And Portal (`LH-profile`, ~2.5 min)
1. Front page: the **Your sessions** card is the way in now. Click
   **New here? Create your profile** under it. (One sentence: the profile pill
   row under the wordmark still opens the same hub, for anyone who knows the
   old path.)
2. **Create profile**: type a class login code, name, username; pick avatar +
   theme (wizard steps in order).
3. **Sign out** (link under the card) → type your username right on the card →
   **Sign in** → the card greets you by name (no password, linger on that).
4. Portal: session card with position, to-do badge, unseen-notes badge;
   click **Open Cueola**, then back, then **Notes**.

## V3 · Build A Rundown (`LH-cueola-build`, ~3 min)
1. **Blank Slate** → new code.
2. **Add Row** ×3; set one row **Timed**, one **Flex**.
3. Click cue cells: add a Video cue, an Audio cue, a Script cue.
4. **Edit** mode: drag-reorder a row, rename a label.
5. Dashboard (second window): open a finished session → **Next Episode**
   panel → **Start Next Episode →**; show the auto-name and ↳ From chip.

## V4 · Run Live Without Panic (`LH-cueola-live`, ~3.5 min)
1. **Go Live** from demo; camera on the pre-live checks incl. **Playout
   first GO**.
2. Show the link strip (CLOUD · TALENT · PLAYOUT · SCRIPT) + caller badge.
3. Advance with arrows; click a row.
4. Advance onto a linked row (GO button or arrows) → automatic call READY ·
   TRACK · ROLL · TAKE; run it again and abort with **S**.
5. Toggle **Manual TAKE (armed call)**: advancing arms, **TAKE · G** fires.
6. Paste a line into the question lane → Enter → talent shows the QUESTION
   card → Esc clears.
7. Kill the talent window → TALENT dark → **System status** → **Recover
   Flowmingo**.

## V5 · Prep The Show Package (`LH-plandabear`, ~4 min)
1. Enter with a profile; open **Planda Bear**.
2. Call Sheet: fill three fields. Flip through Schedule / Safety Plan / patch
   sheets.
3. Production Notes: post, tag a department, reply in a thread, @-mention.
4. To-Do with assignee; checklist with per-item owners; show them landing on
   a portal (second window as the student).
5. Pin a note; show **Seen by**.
6. Group bar: **Reviewing** picker (instructor) and **Switch group**
   (student); **Pick your group** door.
7. **Export PDF Package** → preview → stamp.

## V6 · Set Up The Talent Display (`LH-flowmingo-talent`, ~2.5 min)
Click-path follows the lesson steps: open Talent Display, enter code, READY,
local Controls once (speed/size/mirror), fullscreen, then hands off.

## V7 · Run The Remote Prompter (`LH-flowmingo-remote`, ~3 min)
Remote Op beside a talent window: Play, brake/boost holds, size keys,
direction flip, Reset; end on sent-vs-applied status while killing the talent
window mid-command.

## V8 · Cue And Play Media (`LH-outrangutan`, ~4 min)
1. Home card → **Session** mode.
2. Drop three files; trim one in the clip editor (waveform on audio).
3. Continue modes: Manual / Continue / Follow on three cues.
4. SFX Board: drop a sound, name it, hotkey it, fire it.
5. Output window to a display, **Identify**.
6. Link a rundown row to a cue; advance in Live → auto-fire.
7. **+ Learn a control** with a MIDI pad (or `Outrangutan.midiInject` in the
   console when no hardware).
8. **Cmd+S** → .ogshow; print the show pack.

## V9 · First Fixes (`LH-support`, ~2.5 min)
Stage each symptom, then the fix: mismatched code; blank Flowmingo → push from
Script Op; sent-not-applied → reload talent; wrong row → Prev/Next; stale
paperwork → reopen PB; damaged rundown → **Settings ▸ File ▸ History** →
restore a cloud snapshot (show the confirm wording + recovery copy).

## V10 · Instructor Quick Start (~5 min)
Follow [INSTRUCTOR_QUICK_START.md](INSTRUCTOR_QUICK_START.md) top to bottom on
the dashboard: mint a Class Key → create a session with **Entry
Requirement** → paperwork preset → groups + lock → roster/portal tour →
**Start Next Episode** → term-end revoke. Script = read the Quick Start
sections aloud.

## V11 · Sign In And Join Your Show (`v22-signin`, ~2 min)
1. [0:00] Front page, no one signed in. Camera rests on the **Your sessions**
   card. Say the card's own promise: sign in with your username and the
   sessions assigned to you are one tap away. No password.
2. [0:15] Type a username into the card → **Sign in**. The card flips to
   "Hi," your name, and @username underneath.
3. [0:30] The assigned-session list: each row shows the code, the show name,
   and **Open**. Tap one → you land in the rundown. Say: one tap, and every
   join check still runs; it is the same door, just closer.
4. [1:00] Come back to the front page (topbar home). Point at the links under
   the card: **All sessions & notes** opens your portal, **Sign out** does
   what it says.
5. [1:15] The fallback: click **Have a show code?** below the card → the
   familiar join dialog. Type a code. Say: new codes are the year-month plus
   four letters, like 2607KWXR; older shorter codes still work. Guests and
   remote operators arrive this way with only a code.
6. [1:45] New students: point at **New here? Create your profile** (do not run
   the wizard, V2 covers it). End on the signed-in card.

## V12 · KeyWi Bird Setup And Custom Keys (`v22-keywi`, ~4 min)
1. [0:00] Front page → the **KeyWi Bird** card. Read its line: run playback,
   rundown, prompter, and mics from any Stream Deck. Sign in, then connect.
   Show that a signed-out click asks for sign-in first; sign in and enter.
2. [0:20] Open the **Setup wizard**. Step 1: the wordmark and "One deck. The
   whole rig." Say: five quick steps, only the deck is required.
3. [0:35] Step 2, **Connect your deck**: quit the Elgato Stream Deck app
   first, then **Connect deck**, pick the deck, enjoy the little light show.
   No deck on hand? **No deck? Preview on screen** and the whole video still
   works.
4. [1:00] Step 3, **Micochondria** (optional): hold **TKB** to talk to the
   crew, hold **VofU** to speak to the room; the dot goes green when the
   talkbackd program is running. Skip is fine.
5. [1:15] Step 4, **OBS Studio** (optional): WebSocket Server Settings in
   OBS, then **Connect OBS**. Skip is fine.
6. [1:30] Step 5, **Make it yours**: click through the theme chips and land
   on **Liquid Glass**; the physical keys and the on-screen deck reskin
   together. **Start driving**, pause on the ready toast.
7. [1:55] Click any key to open the key editor, scroll to **Appearance**:
   override the **Label** or **Hide label**; pick an **Accent color** swatch,
   then type a **Custom color (hex)**; search the **Symbol** picker (type
   "wave", pick one of the 85); flip **Progress style** through Wipe, Ring,
   and Bottom bar; show the **Press flash** and **Reactive animation**
   checkboxes; end the beat on **Reset appearance** putting it all back.
8. [3:00] Reactive keys, the payoff: fire an SFX and watch the duration wipe
   sweep behind the icon until the sound ends; show a cue in pre-roll with
   the thin bottom bar; point out a loop pad's corner marker (a loop has no
   end to count down to); every press flashes for a blink.
9. [3:30] The **Brightness** slider; say the deck dims itself to 20 percent
   after five idle minutes and any touch wakes it instantly.
10. [3:50] Close: profiles and pages remember the layout, the theme, and
    every per-key override. Set it once, it is yours.

## V13 · Drill Night: The Break Room (`v22-breakroom`, ~5 min)
1. [0:00] Instructor dashboard: press **Create Test Show**, keep the
   suggested name, confirm. The modal shows the freshly minted show code
   and share link. Say: this code is the drill; hand it to your crew like
   any show code.
2. [0:10] Front page: join the minted session. Assigned crew see it as one
   tap on the **Your sessions** card; anyone else types the code behind the
   **Have a show code?** link. Say: a full late-night talk show (29
   rows), built to rehearse every part of the rig in one sitting.
3. [0:20] Walk the rundown top to bottom, slowly: cold open, monologue, desk
   segments, guest, closer. Click into two script cues so the script pages
   show; point at rows carrying video and audio cues.
4. [1:00] Open **Planda Bear**: the paperwork is complete on purpose. Flip
   through the call sheet, the production schedule with its tech checklist,
   the safety plan, the 12-row video patch, and the 16+1 audio/comms patch.
   Say: this is what "show-ready" looks like; compare yours against it.
5. [1:45] Back to the rundown → **Go Live**. Let the pre-live checks read
   out, then run the top of the show with the arrow keys; take one linked
   row so a cue auto-fires.
6. [2:30] The question lane: paste a line, press Enter, cut to the talent
   window showing the QUESTION card, press Esc to clear it.
7. [3:00] Flowmingo: the talent window follows the script as you advance;
   roll the prompter for a few lines, brake, resume.
8. [3:40] Pads: open the Outrangutan SFX board that ships with the show and
   fire a stinger on a segment change. If a Stream Deck is attached, load the
   show's **The Break Room** KeyWi profile and fire the same pads from
   hardware, duration wipes and all.
9. [4:30] Wrap on the full rundown: run this show before every real one.
   It is the drill night that makes show night boring, in the best way.
